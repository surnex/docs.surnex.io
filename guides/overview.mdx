## Read this first

Two things about how Surnex works explain most early confusion.

**Almost nothing is fetched when you open a page.** Rankings, backlinks, audits, and AI visibility are collected by background jobs and read back from storage. A figure that looks stale usually is — because the job that refreshes it hasn't run yet, or doesn't run on a schedule at all. Only [Trends](/trends/explore) and [Trending now](/trends/trending) are live.

**Only four things refresh themselves.** Rank tracking, backlinks, GEO, and local SEO run on schedules you control. [Audits](/audits/overview), [web vitals](/web-vitals/overview), [domain data](/domains/overview), and [keyword research](/keywords/research) run once at project creation and then only when you ask.

That second point is the one that catches people out. An audit score months out of date usually means nobody has run a crawl since the project was created.

Full detail: [How data collection works](/projects/data-collection).
